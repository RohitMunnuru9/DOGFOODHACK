# White dashboard concepts

Generated with the built-in image generation tool. These are visual exploration mockups with illustrative content, not screenshots of the implemented application.

## 01-neumorphism

Use case: ui-mockup. Create ONE high-fidelity desktop web app dashboard screenshot, landscape 16:10, sharp readable typography, front-on flat view, no device frame, no surrounding scene. This is the DOGFOOD hackathon submission and judging platform, organizer dashboard. Design a polished usable application, not a marketing landing page. All surfaces white or subtly warm off-white. Text warm graphite gray with legible contrast, NOT pure black. Absolutely no blue, purple, violet, black panels, dark mode, colorful gradients, rainbow charts, generic AI sparkles, robot mascots, hero illustrations, decorative floating shapes, or irrelevant finance graphs. Use a tiny muted terracotta accent for primary action, gentle sage for positive statuses, otherwise white and warm grays.
Consistent content: slim 220px sidebar with DOGFOOD wordmark, event switcher 'DOGFOOD 2026', links 'Overview' selected, 'Submissions', 'Teams', 'Judging', 'Results', and 'Settings' at the bottom; footer avatar 'Manu' and 'Organizer'. Main header eyebrow 'EVENT WORKSPACE', title 'Event overview', short subtitle 'Everything you need to keep the event moving.' Top right understated 'View public gallery' and primary 'Invite judges' button. Compact event phase strip: 'Submissions open' then 'Judging' then 'Results', with note 'Closes Sep 29, 18:00 UTC'. Restrained metrics integrated in one horizontal band: '41 projects', '12 judges', '122 / 132 reviews'. Main content is a useful wide submissions table beside a narrower judging panel. Table heading 'Recent submissions', search control, columns 'Project', 'Team', 'Track', 'Status', five elegant rows: 'Local Lens / Northstar / Open / Submitted', 'Patchwork / Paper Plane / Open / Submitted', 'Sprout / Greenroom / Climate / Draft', 'Relay / Fourfold / Open / Submitted', 'Loop / Common Ground / Climate / Submitted'. Small tasteful square project marks, no stock avatars. Right panel 'Judging progress', 92% completion, '10 reviews remaining', three judge rows and horizontal progress indicators, 'Manage assignments' action. Lower compact section 'Needs attention', rows '3 projects still in draft' and '2 judges need assignments', each with a small action arrow. Precise alignment, ample useful whitespace, restrained number of containers, no grid of identical oversized KPI cards. Content is illustrative.
STYLE 1 — SOFT NEUMORPHISM. White-on-white tactile interface. Very subtle raised and recessed surfaces, diffuse warm-gray shadows down-right and white light top-left. Sidebar blends into the canvas; active Overview is an inset pill. Main table sits on one broad softly raised slab with 18px corners; nested rows remain flat and clean. Search is gently inset. Rounded primary button has a tiny tactile raised edge. Narrow progress bars recessed into white surface with muted sage fill. Swiss humanist sans typography with a precise hierarchy, strong medium-gray text. This must look like a restrained professional operating dashboard with carefully tuned neumorphic materials, not an overblurred low-contrast accessibility failure. No glossy glass, no huge bubble buttons, no 3D illustrations.

STYLE 2 — WHITE CLAY INTERFACE. Soft matte porcelain-like white clay components, clearly distinct from flat design and subtle neumorphism. Rounded squircle containers with visible but tasteful thick soft edges, short ambient shadows and gentle convex white volume. A few miniature functional clay icons for sidebar and status, without any decorative toys or mascots. The sidebar is a slim rounded white rail; selected Overview is a soft terracotta-tinted clay tab. One broad rounded table surface with flat legible rows, and a rounded judging module with a simple chunky white-and-sage completion ring. Buttons feel gently pressable, matte clay, no gloss or plastic. Friendly refined rounded sans typography, confident large title, generous air, sophisticated warm white composition. Keep dense information readable and real, do not turn the dashboard into a children's app. No cartoon animals, no oversized illustrations, no gradients beyond natural material shading.

STYLE 3 — EDITORIAL / SWISS UTILITY. An exceptionally refined white dashboard based on typography, structure, and hairline rules. Flat pure white surfaces, square-to-6px corners, almost no shadows. Fine warm-gray dividers and understated selected navigation with a thin muted terracotta rule. A beautifully typeset substantial serif heading 'Event overview' paired with precise restrained humanist sans-serif UI labels and tabular numbers. Asymmetrical balanced composition: wide useful table and slim right-hand activity/judging column, one horizontal metric band divided by hairlines, meticulous baseline grid and breathable spacing. Compact understated controls; a single small terracotta filled action button, white secondary buttons. Status labels use tiny sage dots instead of a sea of colored pills. No neumorphism, no clay volume, no pill-card soup, no decorative illustration, no giant wasted hero. It should feel bespoke, calm, credible, and crafted by a senior product designer.
